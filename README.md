File Backup Monitoring System

About the Project

This project is developed using Python to automatically back up new and modified files. It also detects deleted files and sends email alerts.

Features

- Automatic file backup
- New and modified file detection
- Deleted file detection
- Email notifications
- Automatic monitoring every minute
- Activity logging

Technologies Used

- Python
- File Handling
- Hashlib
- SMTP
- Schedule Module

Requirements

- Python 3
- schedule library

How to Run

1. Install dependencies:
   "pip install -r requirements.txt"

2. Create a "my_files" folder.

3. Configure email environment variables.

4. Run the program:
   
   "python "Automated backup and file monitoring system.py""
